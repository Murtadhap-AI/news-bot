🤖 Auto News Agent
مساعد ذكي ومستقل (AI Agent) يراقب الأخبار التقنية العالمية على مدار الساعة، يفلترها، ويلخصها بأسلوب "سوالف أصدقاء"، ويدزها إلك مباشرة على التليجرام أول بأول بدون تكرار أو إزعاج.

🛠️ هيكلية المشروع (Architecture)
المشروع مقسم إلى طبقات مستقلة (Modular) لسهولة التطوير والصيانة:

news_fetcher.py: رادار سحب الأخبار عبر الـ RSS + قاعدة بيانات SQLite لمنع تكرار الأخبار.

ai_agent.py: عقل الذكاء الاصطناعي (Gemini) لتقييم أهمية الخبر وتلخيصه بأسلوب لطيف.

telegram_bot.py: واجهة الإرسال لتسليم الملخص للتليجرام.

main.py: المشغل الصامت الذي يفحص الأخبار بشكل دوري (كل 5 دقائق)
